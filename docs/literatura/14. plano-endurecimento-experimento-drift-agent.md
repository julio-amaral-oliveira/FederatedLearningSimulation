# Drift Agent Experiment Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> `subagent-driven-development` (recommended) or `executing-plans` to implement
> this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tornar o experimento síncrono do drift agent reproduzível,
auditável, executável em matriz e corretamente comparável sob um horizonte
fixo.

**Architecture:** `smoke_drift.py` continua sendo o controlador do episódio;
`DriftMonitor` registra o trace de detecção; `drift_results.py` centraliza
schema, validação, resumo e compatibilidade; adapters de controle ficam fora do
monitor. Corrupções e calibração permanecem módulos independentes consumidos
pelo runner.

**Tech Stack:** Python 3, `unittest`, PyTorch, NumPy, Matplotlib e JSON.

## Global Constraints

- Manter somente o fluxo federado síncrono neste experimento.
- O detector recebe somente `x`, sem rótulos.
- No máximo um bloco de retreino por episódio.
- Preservar leitura dos artefatos schema v2; novas execuções usam schema v3.
- Não adicionar dependências externas.
- Executar TDD: teste vermelho, implementação mínima, teste verde.
- Cada tarefa termina em commit independente.
- Não fazer push nem adicionar trailers `Co-authored-by`.
- Preservar todas as alterações locais preexistentes fora dos arquivos da
  tarefa.
