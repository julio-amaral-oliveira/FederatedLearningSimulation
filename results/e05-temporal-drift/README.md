# E05 — Drift temporal

Este diretório contém o estudo histórico que alterna grupos de classes do
CIFAR-10 durante o treinamento.

- `cifar-10/raw/` contém os JSONs brutos.
- `cifar-10/plots/temporal/` contém os gráficos usados pelo relatório.
- `cifar-10/plots/corrupted/` contém uma variante histórica com corrupção.
- `mnist/qa/` contém uma execução pequena para QA.

Este estudo não é o drift agent do E07. Ele usa mudança temporal de classes.
