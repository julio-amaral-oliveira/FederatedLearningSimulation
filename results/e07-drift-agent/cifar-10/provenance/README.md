# Proveniência do E07

Este diretório preserva as cópias importadas que deram origem à publicação
oficial do E07.

- `matrix-source/` contém a matriz importada e o smoke separado.
- `calibration-source/` contém a calibração oficial importada.

Use `../uniform/matrix-v1/` e `../calibration/` como os destinos publicados.
Não edite estes arquivos para criar uma nova execução.
